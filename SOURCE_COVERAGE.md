# Source coverage and publication boundary

## Coverage

- **Week 7 — Temporal Data:** temporal semantics, valid and transaction time, temporal tables, SQL range queries, point/sequence representations, arrays and time-series SQL.
- **Week 8 — Unstructured Data:** structured versus unstructured data, image and text features, supervised and unsupervised learning, Bag of Words, TF–IDF, embeddings, BERT/GPT and metadata.
- **Week 9 — Stream Processing:** DBMS versus DSMS, pub/sub, MQTT, Kafka, windows, event time, watermarks, delivery guarantees, state and the tutorial message flow.
- **Week 10 — Scalable Data Engineering:** scaling, storage layouts, partitioning, replication, CAP, MongoDB sharding, HDFS, MapReduce, Spark, PySpark and Flink.

Lecture slides, transcripts and tutorial files were reviewed during development. The public site contains a rewritten study interpretation rather than copies of those source documents.

## Not included in this public branch

- course PDFs, lecture recordings and transcripts;
- tutorial notebooks and raw datasets;
- account credentials or configuration files;
- local Java, Python, Spark or browser runtimes;
- deployment identifiers and intermediate build archives;
- screenshots copied from course teaching material.

The W10 Bitcoin plot is a derived execution result. Its caption states that it comes from the tutorial workflow; the underlying raw dataset is not redistributed.
