# Project record

## 1. Problem and objective

The initial revision notes were comprehensive but text-heavy. The practical problem was not merely a lack of information: the learner found it difficult to stay engaged, recognise English terminology in quiz questions, and connect abstract concepts to SQL or PySpark examples. The objective therefore became a browser-based study guide that would make the same scope easier to navigate and practise.

## 2. Iterative process

1. Reviewed all available Week 7–10 lecture, transcript and tutorial materials.
2. Compared the stated scope with the style of Quiz 1 questions to identify likely question patterns without removing lower-priority material.
3. Organised the syllabus into 48 lessons under four week-level modules.
4. Rewrote each lesson for a beginner using diagrams, comparison tables, code examples and bilingual terminology.
5. Added search, week filters, lesson navigation, local progress tracking and one-minute checks.
6. Validated the static build in a real browser, including navigation, filtering, quiz feedback and responsive presentation.
7. Published the site and prepared this public-safe repository without distributing original course files.

## 4. Human and AI contribution boundary

The learner set the goal, supplied the authorised course materials, corrected scope and presentation problems, required complete week-by-week coverage, and accepted or rejected iterations. AI assisted with document synthesis, information architecture, explanatory writing, HTML/CSS/JavaScript implementation and QA. The final artefact should therefore be described as an **AI-assisted study product directed and verified by the learner**, rather than as code written independently without assistance.

## 5. Skills demonstrated

- turning an ambiguous learning problem into explicit product requirements;
- iterative review and acceptance of AI-generated work;
- source coverage checking and evidence-based presentation;
- basic static web architecture and client-side state;
- communicating technical concepts with visual and bilingual support;
- separating publishable artefacts from restricted source materials and credentials.
