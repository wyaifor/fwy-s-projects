# MSP430F5529 智能循迹小车控制

> 本科课程实战项目。公开内容仅包含已核验、无个人信息的控制源码与项目说明；原始课程报告、照片、测试表、课程资料和硬件工程文件均未公开。

## 项目目标

基于 **MSP430F5529** 实现五路红外循迹小车的基础控制与测速显示。代码读取红外传感器状态，在定时器中断中调整舵机 PWM；同时设置直流电机 PWM，并将计数结果显示在四位数码管上。

## 已核验的实现

- 使用 MSP430F5529 定时器配置舵机和双路直流电机 PWM；
- 依据 `P6IN` 的五路循迹输入区分大幅/小幅左转、直行和大幅/小幅右转；
- 在定时器中断中执行循迹控制；
- 包含计数/显示相关逻辑，课程材料记录了基于定时器与上升沿捕获的测速尝试。
