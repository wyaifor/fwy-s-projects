# 基于 LangChain 和 ChatGLM 的电子工艺实习智能问答系统

> 本科毕业设计｜北京信息科技大学智能科学与技术专业｜2025 年 2–6 月

## 项目概述

本项目面向电子工艺实习中的重复性知识问答场景，基于 LangChain 与 ChatGLM 构建本地知识库问答系统。论文材料记录了从课程资料整理、文本预处理、向量检索与提示词问答，到本地部署和对比测试的完整研究流程；系统面向知识点查询、实验指导建议和讨论交流等教学辅助场景。

## 报告记录的测试结果

论文第 5 章记录：本地专业知识库在其测试集上的问答准确率为 **76.04%**、专业相关度为 **85%**、平均响应时间为 **9.75 秒**；所比较的通用大模型对应数值为 69.34%、50% 和 2.01 秒。该指标为论文历史测试结果，**仅作报告归档，不是本次重新运行验证的结果**。测试口径与限制见 [报告结果说明](evidence/report-derived-results.md)。

## 技术与流程（依据论文）

1. 汇集电子工艺实习、模拟电子技术与数字电子技术等课程资料。
2. 对文本进行 OCR、清洗、人工校对与按主题整理。
3. 以 LangChain 组织文档加载、切分、嵌入与向量检索，并由 ChatGLM 结合检索上下文生成回答。
4. 使用问答测试集，按文本处理、语言对齐、相似度与阈值规则统计问答准确率与专业相关度。
