# 基于 OpenCV 的手势识别与交互控制

> 本科人工智能工程实战课程项目。公开内容只包含经核验的 Python 程序和脱敏说明；课程报告、PPT、硬件仿真资料、截图和原始文件均未公开。

## 项目目标

实现一个基于 OpenCV 的手势识别原型，可从摄像头或本地图片/视频获取画面，对皮肤色彩范围进行分割并识别 1–5 的手势数量。课程材料还记录了将识别结果用于嵌入式控灯交互的设计与仿真思路。

## 已核验的实现

- 将 BGR 图像转换为 HSV，并用阈值区间提取候选手部区域；
- 使用形态学闭运算与膨胀抑制区域碎片；
- 通过轮廓、`approxPolyDP` 和点间距离规则估计 1–5 的手势；
- 提供 Tkinter 界面，可选择本地文件或打开摄像头并调节距离阈值。

## 公开代码与边界

- `src/hand.py`：来自本人课程归档的原始 Python 程序，仅调整文件路径和项目说明，不把课程原型包装成生产级模型；
- 程序依赖 Python、OpenCV、NumPy、Pillow 与 Tkinter；没有提供模型权重、训练数据或性能基准；
- 课程报告提出过准确率目标，但没有可公开复核的最终测试集和指标，因此**不对外宣称准确率**；
- 已知限制包括肤色阈值和复杂背景对结果的影响，当前仅覆盖 1–5 手势。

可在具备上述依赖的本地 Python 环境中执行 `python src/hand.py`。摄像头权限、运行稳定性和不同平台兼容性尚未重新验证；这是课程阶段代码，不承诺即开即用。
